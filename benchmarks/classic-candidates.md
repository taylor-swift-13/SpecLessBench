# 经典算法与数据结构：后续候选

以下是待构造候选，并非已完成的 benchmark 任务；每项仍须固定程序、三平台定理、差分测试和成本记录。

更新：表中的全源最短路和强连通分量已在 [graphsuite-core](tasks/graphsuite-core/README.md) 落地；原候选表保留作为设计历史。

本轮补充了[来源、输入与观察边界、反例设计及初步筛查](research/classic-comparisons.md)。现有库已经包括并查集连接性和朴素匹配／KMP；后续新增实现须保留在对应原家族，避免重复计算数据划分与结果。

| 家族 | 实现对 | 输入与观察边界草案 | 反例方向 |
| --- | --- | --- | --- |
| 最短路径 | Floyd–Warshall / 对每个起点运行 Dijkstra | 非负带权有向图；观察不可达标记与全部距离，不比较路径选择 | 改动不可达判断或松弛条件 |
| 并查集 | 朴素合并 / 按秩合并加路径压缩 | 合法 union/find 操作序列；观察连通查询，不比较内部根编号 | 错误的路径压缩 |
| 强连通分量 | Tarjan / Kosaraju | 有向图；观察两点是否属于同一分量，不比较分量编号或枚举顺序 | 忽略反向边 |
| 排序 | 稳定归并 / 稳定计数排序 | 有界整数 key 和 payload；观察完整序列及相等 key 的顺序 | 计数回填方向导致失稳 |
| 拓扑排序 | 入度队列 / 深度优先遍历 | 有向无环图；两个有效拓扑序不必相同，须先固定共同的确定性选择规则或改为验证明确的关系观察 | 忘记递减入度 |

优先选择实现结构有实质差异、输入观察能独立说明且反例有清晰来源的家族。尤其不应把不同但同样正确的输出误标成行为差异。
