# Candidate source register

This register records candidate sources for task construction. Sixteen selected raw C snapshots are now stored in [source-material](source-material/README.md), with preserved source/license notices and an [import manifest](source-material/import-manifest.json). They are curator material, contain some source-system contracts, and are not evaluation-ready tasks. A repository-level license does not override embedded upstream notices.

The first concrete derived revision is [tasks/qcip-core](tasks/qcip-core/README.md): BST, AVL, ring buffers and Dijkstra, with 16 C entries and12 unproved task targets. Its [adaptation log](tasks/qcip-core/PROVENANCE.md) distinguishes source-derived ports from authored alternatives, normalized APIs and deliberate mutants. Copies of all three applicable license files accompany that source closure. No upstream-to-adaptation equivalence or new task certificate has been proved.

The license and provenance record for a released task must include the exact upstream commit, source paths, copyright/license notices, task-local modifications, and the certificate history created for SpecLessBench. The commits and repository-level license metadata above are an initial screen, not a task-level legal clearance. If redistribution is unclear, the task is rewritten from the algorithmic idea and the provenance states that it is newly authored rather than copied.
