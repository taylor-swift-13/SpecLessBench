# 经典算法：生成森林与稳定排序

本批次含两组实现、五个语义上下文，每个上下文都有 Lean、Rocq 和由 C 导出的 CompCert Clight 目标。等价分支与具体反例分支均为待证明命题；测试标签不是形式化证明。任务清单与源码哈希见 `groups.json`，实际 Clight AST 与导出信息见 `compcert/`。

## 最小生成森林

输入为 `[mode,n,m,u0,v0,w0,...]`：`1 ≤ n ≤ 8`，无向简单图的边满足 `0 ≤ u < v < n` 且端点对不重复，边权在 `[-1000,1000]`。允许不连通图与负边权。Kruskal 按权选边并使用并查集；Prim 扫描跨割边并逐分量生长。

* `MST-TIED-WEIGHT`：`mode = 0`，允许相同边权。比较森林总权重和连通分量数；不观察选边。不同最小森林在此观察下可相等。
* `MST-UNIQUE-EDGES`：`mode = 1`，要求所有边权互异，额外比较所选输入边的位掩码（输入第 i 条边对应第 i 位）。
* `MST-MAX-COUNTEREXAMPLE`：相同输入域和观察下比较最小 Kruskal 与最大生成森林变体；预期可找到反例。

这些目标仅比较固定实现的输出，不额外证明输出确为最优森林。在边权相同时不能要求两种算法选择同一组边。

## 稳定记录排序

输入 `[n,key0,payload0,...]`，`0 ≤ n ≤ 64`，每个字段属于 `[-1000,1000]`。观察完整的 `(key,payload)` 输出序列，排序键为 key，原始相等键的 payload 顺序因此可见。

* `SORT-MERGE`：稳定插入排序与稳定归并排序；归并遇到相等键时先取左侧。
* `SORT-UNSTABLE`：稳定插入排序与交换式选择排序；后者可能改变相同键记录的相对次序，预期可找到反例。

例如输入 `[(1,1),(1,2),(0,3)]`，稳定输出为 `[(0,3),(1,1),(1,2)]`，选择排序可输出 `[(0,3),(1,2),(1,1)]`。

## 测试与成本

图任务 11,064 个不同输入（含四点图小域穷举、边界和随机），排序任务 13,119 个不同输入（含长度至 7 的三值键穷举、边界和随机）；各组各请求 10,000 次随机生成。每个输入对三种实现分别执行 C、Lean 和提取的 Rocq，合计 217,647 次行为执行；比较输入域的执行另计。没有非预期差异，两个反例任务分别有 5,559 和 10,508 个区分输入。可复现种子、各上下文覆盖、记录的具体见证及哈希见 `evidence/`。

C 使用 GCC 和地址／未定义行为检查器执行；Clight AST 和待证明目标通过类型检查，但未执行 Clight 语义，也没有证明最终目标。构造问题、修订和每组成本见 `benchmarks/construction/`；Rocq 首次对大图测试因提取的自然数位掩码运算导致栈溢出，改用二进制整数后重新完整测试。共享模型 token、并发进程树峰值与远端模型内存不可精确按组分配。
