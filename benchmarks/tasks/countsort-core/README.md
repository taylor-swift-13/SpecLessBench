# 稳定插入排序与计数排序

这一组包含两道待证明任务：`COUNT-01` 比较稳定插入排序与稳定计数排序；`COUNT-02` 比较稳定插入排序与反向读取输入的计数排序变异。每题均有 Lean、Rocq 和 C/CompCert 的固定实现、等价目标及具体输入反例目标，最终命题均未证明。

输入为 `[n,key0,payload0,...]`，其中 `0 ≤ n ≤ 64`，key 属于 `[-3,3]`，payload 属于 `[-1000,1000]`。观察完整的排序后 `(key,payload)` 序列；相同 key 的记录顺序因此可见。计数实现先计算每个 key 的频数及输出起点，再按输入顺序填入；变异按反向输入顺序填入，可能破坏稳定性。例如 `[(0,1),(0,2)]` 会被变异交换。

三平台完整差分覆盖 13,126 个不同输入、118,134 次行为执行；没有非预期差异。变异在 12,631 个输入上不同。语料包括三值 key 的短序列穷举、边界情况和 10,000 次随机生成尝试，并对重复输入去重。整理端另用 Python 稳定 key 排序复核全部 C 参考输出；该程序不是求解器收到的功能规约。`evidence/` 保存语料、输出、哈希和具体见证。

该实现组与已有 `stable-record-sorting` 共用切分家族。C 测试使用 sanitizer；Clight AST 与待证明目标通过类型检查，但没有执行 Clight 语义，也没有证明最终目标。成本和问题记录见 `benchmarks/construction/`。
