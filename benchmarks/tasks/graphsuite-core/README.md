# 全源最短路、强连通分量与 Boyer–Moore

三组各包含三个固定实现，形成六个上下文；每个上下文分别提供 Lean、原生 Rocq 和由 C 导出的 Clight 目标。每个目标同时提供 `equivalence` 和固定输入及观察的 `refutationAt` 命题；求解器须选择具体分支。实现和目标见 `groups.json`、`lean/GraphSuiteGoals.lean`、`rocq/GraphSuiteGoals.v` 和 `compcert/*Goals.v`，均未证明。

## 全源最短路

输入为 `[n, matrix...]`，`1 ≤ n ≤ 8`；矩阵按行排列，`-1` 表示无边，非对角边权为 `0..100`，对角必须为 `-1`。允许零权边、多个等长路径和不连通图。输出为按行排列的全部源点／终点距离，`-1` 表示不可达；内部路径和前驱不作为观察。

* `APSP-01`：Floyd–Warshall 对逐源 Dijkstra。
* `APSP-02`：Floyd–Warshall 对错误地忽略零权边的 Dijkstra 变异；预期存在反例。

这两个固定实现的等价目标只要求相同观察，不附加一份独立的最短路径规约。距离计算使用有界整数和内部哨兵 `1000000`，有效距离远小于该哨兵。由于逐源实现与已有单源 Dijkstra 任务相关，中心化切分策略将两者放在同一 `qcip-dijkstra` 家族；原实现组清单保持其测试时的哈希。

## 强连通分量

输入为 `[n, matrix...]`，`1 ≤ n ≤ 8`，矩阵每项为 0 或 1，表示有向边；允许自环。输出 `n × n` 布尔矩阵，第 `(i,j)` 项表明两个顶点是否属于同一分量。**不比较分量编号或遍历顺序**。

* `SCC-01`：Tarjan 的 DFS、lowlink 和活动栈，对 Kosaraju 的两轮 DFS 与反图。
* `SCC-02`：Tarjan 对第二轮错误地使用原图的 Kosaraju 变异；预期存在反例。

## 子串首次匹配

输入 `[n,m,text...,pattern...]`，`0 ≤ n ≤ 48`、`0 ≤ m ≤ 16`，每个元素属于字母表 `0..3`。输出首次匹配位置；空模式返回 0，无匹配返回 -1。此处使用 Boyer–Moore 的**坏字符规则**，不声称实现完整的好后缀规则。

* `BM-01`：朴素逐位置匹配对坏字符跳跃。
* `BM-02`：朴素匹配对发生不匹配后固定跳过整个模式的变异；预期存在反例。

BM 任务与已有朴素匹配／KMP 任务共用 `first-match-search` 切分家族，避免共享代码或题目语义跨训练／测试划分。

## 构造和证据

这些实现是为本基准新写的有界程序；算法来源和选择依据见 [经典算法候选](../../research/classic-comparisons.md)。三组分别测试 12,495、6,442、13,859 个不同输入，合计 32,796 个输入、295,164 次行为执行；各组各请求 10,000 次随机生成并穷举显式小域，重复输入已去除。未发现非预期跨平台差异，三个变异分别有 4,737、5,670、794 个区分输入。

另外对全部选定输入使用整理端独立算法复核 C 参考输出：逐源 Bellman–Ford 复核距离、逐点广度优先可达性复核分量关系、直接切片扫描复核匹配；这些检查也未发现差异。这些整理端程序不作为提交给模型的规约。

`evidence/` 记录测试语料、哈希、逐平台对比、覆盖、独立复核和具体区分输入；`benchmarks/construction/` 记录问题、修订与每组成本。测试通过仅提供有限输入上的证据，并不证明最终命题。C 执行使用 sanitizer；Clight AST 是形式化目标，未运行其语义。构造阶段不尝试证明最终定理。
