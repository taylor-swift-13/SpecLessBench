# EqualBench的实际构造方法

本方法用于构造待证明问题，不在本阶段证明最终命题。它与冻结后的proof-only求解严格分开：构造者可以修改实现、域、观察或任务；求解者只能提交等价或反例证书。

1. **以实现组选择推理差异。** 一组固定多个实现，选少量有不同挑战的实现对；记录算法、控制流、表示、内存或调用差异，暂定L/W等级。避免两两组合膨胀，也避免把跨语言移植算成独立家族。
2. **固定最小比较边界。** 输入类型/布局、范围、C安全前提和可观察值由代码精确定义；不另给独立功能后置条件。观察必须足以暴露API行为，例如队列found/value、矩阵全部单元、树map查询和最终读出；不可无故比较整块堆。
3. **落实三平台的具体实现。** 每个上下文提供Lean、原生Rocq和C/CompCert。所有可达callee闭合；分配/日志/布局适配明确记载。原生移植可能改变物理表示和调用结构，因此按平台标注风格，不声称逐行等同或形式化精化。
4. **先检查定义和目标类型。** 原生实现可执行，C通过真实clightgen生成AST；目标直接引用这些实现。公开两个独立分支：全域等价，以及参数化到具体见证的反例。禁止用参数、`sorry`、`Admitted`或两个失败结果相等来补空位。类型检查通过不等于证明目标。

   反例有具体输入和观察，保护前端检查专门化命题。裸析取Prop证明不计分，以避免经典逻辑的非构造性绕过。全体58上下文的两个分支类型均已检查，详见[证明接口](../benchmarks/proof-interface/v1/README.md)。
5. **分层生成并审计输入。** 固定见证与边界输入、小域穷举、结构偏置的随机输入并行使用。随机必须覆盖不均衡结构、重复、空输入、绕回或重叠前缀等相关现象。新批次去除重复输入，并交叉执行Lean/Rocq有效域判断及非法邻界输入，避免生成器与定理域错位。
6. **同时比较两个方向。** 组内比较候选正向实现；跨语言比较同一变体的观察；负例实现要求实际有区分输入。输入合法却失败、域判断不一致、意外正向差异、移植差异分别建问题记录。C sanitizer执行不等于Clight语义执行。
7. **把发现变成可审计修订。** 先保留原始输入和两边观察，再决定修复实现、修复生成器/序列化/观察，或保留不等价上下文。改变域须说明范围变化，不能静默排除反例。修改前保存源码快照，修改后记录新hash、原因、受影响任务、新revision及重测。短见证只声称在已测集合中最短，除非另有全局最小性证据。
8. **冻结问题而非伪造真值。** 三版实现、域/观察、目标、AST、工具版本/二进制hash及测试语料指纹一起冻结。无反例只能产生暂定等价标签，负例的执行见证也不是Rocq安全执行证明。保留相反证书审计入口，最终求解仍以内核接受为准。
9. **按组计量全部尝试。** 编写/构建/失败/修复/测试成本保留，按组汇总，嵌套命令不重计。共享模型usage单独一次；不能准确拆组时标未知，不硬均摊。区分最大单进程RSS、并发进程树峰值和远端推理内存；只能观测到的项目才填数。

本方法已用于QCIP四组、基础算法六组、边界语义/数据结构八组及状态历史三组。前一批的测试记录按执行输入计数；后续批次增加去重和有效域交叉审计。总体报告必须区分输入记录、唯一输入、行为求值次数、域判断次数、语义上下文和平台实例，不能相互替代。

选取规约难以完整另写的任务时，记录具体特征：编码、错误优先级、错误位置、失败时已提交前缀、状态相关解释、短路忽略错误等。字节范围与传输长度是域条件，格式错误和运行时错误结果仍须保留。特征标签不是已测得的规约编写难度，也不自动赋予L4；索引/后缀解析共享受保护单记录函数，和不同数据表示/求值策略应分别分析。测试分别报告参考成功/错误类别的实际分布，不能用“所有类别至少一次”替代全面覆盖。

v0.4计量审计发现复用旧模块的import副作用重置了部分批次标签。原记录未改写，追加`attribution-corrections.jsonl`覆盖归属，`cost_attribution.py`供汇总统一解析；八组全量重测，所有尝试仍计费，重复输入不扩大覆盖数。汇总对旧schema的假设和检查器变量顺序错误也有失败/修订记录。前期部分prepare/audit命令缺少完整进程计量，CPU/RSS明确未知，共享请求墙钟包含其延迟；不宣称已获得无缺口的完整成本。

v0.5进一步对历史敏感任务统计实际操作事件，并从真实Clight AST抽取调用图、检查callee体闭合。主测试发现同feed多帧事件仅1次后，新增独立补充提供器，覆盖环形余数、长帧残留后连续完成多帧、成功前缀后的错误与重置恢复。补充与主语料先去重再运行，绑定各自提供器/语料hash，汇总验证不重叠；主测试报告原样保留。初次补充缺失reset-after-error覆盖也保存为失败，不通过降低门槛解决。输出事件计数和调用深度是结构/覆盖信息，不是已校准的证明难度。全部最终命题仍未证明。

v0.6 将可执行参考扩展到带宽对齐和定点重采样。把可观察行为精确到并列最优方向、有符号半值舍入、边界和饱和标记。登记外部测试场景或数据片段时，记录原始出处、输入映射及快照指纹。报告单列来源输入，覆盖仍由小域穷举、结构化边界和固定种子随机尝试共同提供。经典算法衍生任务可使用合成语料。

当前停止条件为：选定的构造批次全部有具体三平台实现及类型正确的目标，测试覆盖达到预定预算，预期负例确有区分输入，非预期差异均已处理，问题/修订/成本和缺口可追溯。这里不要求最终命题证明，也不表示已完成可隔离发布的proof-agent评测包。
